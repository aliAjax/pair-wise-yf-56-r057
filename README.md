# pair-wise-yf-56 网络安全事件响应作战室

## 源提示词摘要
值班人员接收告警，分析人员补充资产和影响范围，响应负责人批准隔离、封禁或恢复动作，法务和公关维护对外口径。系统展示实时事件时间线、子事件、审批、证据和责任人；高优先级动作双人确认，敏感内容按角色显示，并支持只读演示模式。

## 技术栈
Next.js 15 + TypeScript + App Router + shadcn/ui 本地组件 + Zustand + TanStack Query + React Hook Form + Zod + next-intl + date-fns + dnd-kit。

## 已实现闭环
- 主事件、子事件、处置动作和实时时间线。
- 离线优先协同操作日志：事件、子事件、动作、审批和回执均使用稳定标识，恢复后重放并去重。
- 处置动作乐观锁：两个标签页基于旧版本修改时，后提交一方得到冲突，本页版本和当前版本同时保留，不静默覆盖。
- 隔离动作要求两个不同角色的有效审批；权限或敏感级别变化后，待执行隔离动作立即失效，审批和历史时间线不删除。
- 执行请求、待确认回执、失败保留和幂等重试；已成功的执行结果不会被重复回执重复执行。
- 角色权限控制、敏感内容遮蔽、只读演示模式和跨标签页广播。
- dnd-kit 调整处置优先级；网络与执行器失败可在页面中模拟。

## 协同模型说明
当前实现使用浏览器 `localStorage`、`BroadcastChannel` 和 Web Locks 模拟同一浏览器多个标签页的合并服务，便于无后端演示。真实后端可直接复用 `lib/collab.ts` 中的操作类型、`applyOperation` 归并规则和冲突/回执结构，将本地快照替换为服务端持久化与同步通道。
